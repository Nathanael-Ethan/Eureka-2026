Key Insight

Storage vs Runtime Memory

Understanding the difference between storage compression and runtime efficiency.

Storage Compression

Reduces the size of the model file on disk. This is what most quantization methods optimize for.

  • INT8: ~2x smaller than FP16
  • INT4: ~4x smaller than FP16
  • Binary: ~14x smaller than FP16

Runtime Memory

The memory required during inference. This includes the model weights, KV-cache, activations, and overhead.

  • Decompressed weights may use more memory
  • KV-cache scales with context length
  • Activations depend on batch size

Goal: Direct low-bit computation aims to reduce both storage AND runtime memory by avoiding full decompression.
