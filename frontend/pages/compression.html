Compression Methods

Available Representations

LDMARK supports multiple compression representations with different trade-offs.

FP32 Baseline

Full 32-bit floating point. The original precision for most models. No compression.

FP16 Active

Half precision floating point. 16 bits per parameter. Common for GPU inference.

INT8 Active

8-bit integer quantization. ~8.125 bits per weight with scales. Good balance of size and quality.

INT4 Active

4-bit integer quantization with group-wise scales. ~4.125 bits per weight. Significant compression.

Binary Experimental

1-bit quantization. ~1.125 bits per weight. Extreme compression with significant quality trade-offs.

Ternary Experimental

~1.58-bit quantization with three levels. Middle ground between binary and INT4.

Codebook Experimental

Non-uniform quantization using learned codebooks. Potentially more accurate than uniform methods.
