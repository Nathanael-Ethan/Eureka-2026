Getting Started

Installation & Quick Start

Installation

$ pip install -e .

CLI Usage

$ ldmark inspect path/to/model.safetensors
Inspect model structure and metadata
$ ldmark analyze path/to/model.safetensors --format json
Analyze model parameters and storage
$ ldmark compile input_model.pt output_dir/ --precision int4 --strategy balanced
Compile model with INT4 quantization

Python API

from ldmark.analysis import ModelAnalyzer, load_numpy_dict
from ldmark.compression import quantize_groupwise, QuantizationConfig
from ldmark.hardware import detect_hardware
from ldmark.planning import CompressionPlanner
# Detect hardware and analyze model
hw = detect_hardware()
tensors = load_numpy_dict("model.npz")
analyzer = ModelAnalyzer(model_id="my_model")
analysis = analyzer.analyze_numpy_tensors(tensors)

Compression

Compression Methods

Uniform Quantization Active

INT8 and INT4 quantization with group-wise support.

Ultra-Low-Bit Experimental

Binary (1-bit) and Ternary (~1.58-bit) representations.

Non-Uniform Experimental

Codebook quantization and learned binary representations.

Future Research Future

Mixed precision, direct low-bit computation, compression-aware training.

Supported Hardware

GPU

NVIDIA (CUDA), AMD (ROCm), and Intel GPU support.

Planning

Compression Planning

The LDMARK planner considers multiple factors when selecting a compression strategy:

  • Model characteristics (size, architecture, dtypes)
  • Target hardware capabilities and constraints
  • Storage budget limitations
  • Runtime memory requirements
  • Context length and KV-cache estimates
  • User quality requirements
