Pipeline Stages

Compiler Pipeline

The LDMARK compiler processes models through seven distinct stages.

01
LOAD
Load model metadata and tensors from supported formats.
02
ANALYZE
Examine parameters, tensors, dtypes, architecture, storage, and runtime requirements.
03
PLAN
Choose compression strategy based on model characteristics, hardware, and constraints.
04
TRANSFORM
Apply the selected representation transformation.
05
VALIDATE
Check numerical reconstruction, artifact integrity, size, and metadata.
06
EXPORT
Create a versioned LDMARK artifact with all necessary metadata.
07
RUNTIME
Load and execute the compiled representation on the target hardware.
