Research

Research, Not Magic

LDMARK does not assume that smaller automatically means better. Every transformation should be measured.

Storage

How many bytes does the compiled representation occupy?

Numerical Error

How different is the reconstructed representation from the original?

Behavior

Does the compressed model produce measurably different outputs?

Principles

Research Principles

Five guiding principles for honest compression research.

01

No Fake Compression

Only report measured or mathematically derived results.

02

Storage ≠ Runtime Memory

Never confuse a small model file with low inference memory.

03

Feasibility ≠ Quality

A representation fitting on a laptop does not prove that it preserves model capability.

04

Hardware Matters

The same representation can behave differently across hardware backends.

05

Measure Everything

Compression ratio, reconstruction error, runtime behavior, and memory usage should be independently evaluated.
